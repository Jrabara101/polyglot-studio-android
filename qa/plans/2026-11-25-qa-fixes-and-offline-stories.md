# Critical QA Fixes & Offline Story Café (100 Stories + Kokoro Audio) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix all critical/high/medium QA anomalies across the Android app and landing page, and replace Gemini in Story Café with 100 curated offline branching stories (34 Japanese first, then 33 Spanish and 33 French) backed by 600 pre-generated Kokoro `.m4a` host audio clips.

**Architecture:** Fix `TactileButton` width propagation via `propagateMinConstraints = true`, centralize retryable offline save-state handling across all four remaining game screens, add a `uid`-scoped `SharedPreferences` profile summary cache for zero-flash offline cold starts, and mirror `Lexicon` with a lazy-loaded `StoryCatalog` backed by `assets/stories/{japanese,spanish,french}.json` and `assets/audio/stories/<lang>/<storyId>_<nodeId>.m4a` clips generated by `tools/generate_story_audio_kokoro.py`.

**Tech Stack:** Kotlin, Jetpack Compose (Material 3), Robolectric + Compose UI Test (`junit4`), Android `SharedPreferences` & `MediaPlayer`, Python 3 (`tools/.venv-kokoro` with `kokoro.KPipeline` `hexgrad/Kokoro-82M` + `ffmpeg`), HTML/CSS (`docs/index.html`), GitHub Actions CI.

**Spec:** `qa/specs/2026-11-25-qa-fixes-and-offline-stories-design.md`

## Global Constraints

- Min SDK 24 (Android 7.0+), Compile/Target SDK 36.1, Java 11 source compatibility (no `java.time` in Android runtime code without desugaring).
- Keep all existing 35 unit and Robolectric Compose UI tests passing (`./gradlew testDebugUnitTest -PexcludeEmulatorTests=true`).
- Do **not** remove Gemini from `CalligraphyGameScreen`, `VoiceQuizGameScreen` grading, `QuizGameScreen` `"Fresh AI Set"`, or `TutorHubScreen` — only `StoryGameScreen` goes 100% offline.
- Do **not** modify `tools/generate_audio_kokoro.py` lexicon behavior or overwrite existing lexicon `.m4a` clips.
- Kokoro story voices and settings: Japanese `lang_code="j"` / `jf_alpha` (synthesized from kana `npcReading`, never raw kanji), Spanish `lang_code="e"` / `ef_dora`, French `lang_code="f"` / `ff_siwis`, default `--speed 0.9`, 48 kbps mono AAC `.m4a`.
- Story totals (Approach A, Option 2): exactly **100 stories** (**34 Japanese**: 12 Beginner / 11 Intermediate / 11 Advanced; **33 Spanish**: 11/11/11; **33 French**: 11/11/11), each a **6-node diamond DAG** (`n0` → `n1a`/`n1b` → `n2a`/`n2b` → `n3`), yielding **600 host audio clips** total (**204 JP**, **198 ES**, **198 FR**).
- Specs and plans live under `qa/` (never inside `docs/`, which is the public Vercel static site root).

## Review Focus

1. **Wrap-content vs. constrained-width `TactileButton` coexistence:** Fixing `Modifier.weight(1f)` / `Modifier.fillMaxWidth()` shadow bleed must not stretch compact buttons (`Guide`, `Undo`, `Clear`, `Check`, `Sign Out`, `Talk`) → pinned in Task 1 `TactileButtonTest`.
2. **Offline save failure, retry, and cancellation:** Failing `onCompleteSession` must show `"Not saved yet"` + retry button without crashing, succeed on retry without duplicating state, and rethrow `CancellationException` → pinned in Task 2 (`VoiceQuizGameScreenTest`) & Task 8 (`StoryGameScreenTest`).
3. **Cross-user cache isolation & corrupted local cache:** Signing out or switching `uid` must never leak another user's cached language/XP/name, and missing/invalid cached enum values must safely default → pinned in Task 3 (`ProfileSummaryCacheTest`).
4. **Story graph integrity & Japanese kana pronunciation:** Every story must form an acyclic 6-node diamond graph reaching terminal `n3` in exactly 3 turns, every Japanese NPC node must have non-blank kana `npcReading`, and every NPC node must have an existing `.m4a` clip → pinned in Tasks 6 & 7 (`StoryCatalogTest`).
5. **Story Café runtime edge cases:** Switching stories or difficulty mid-dialogue must reset turns/scores cleanly; tapping the host speaker button must route to the node's bundled Kokoro clip; reaching `n3` must unlock completion and `Next Story` cycling → pinned in Task 8 (`StoryGameScreenTest`).
